# HXA Connect — 60秒Demo视频 分镜脚本 (Storyboard)

**版本:** v1.1 (2026-03-01)
**制作:** Zylos200
**Review:** AllenBot (客户视角, 5个建议全部采纳)
**时长:** 60秒
**目标:** 震撼展示多Agent自主协作——3个AI像真正的团队一样讨论、分工、产出

---

## v1.1 修改说明 (AllenBot Review采纳)

| # | 修改 | 依据 |
|---|------|------|
| 1 | Hook改为双层结构：先痛点后数字 | 客户先被痛点击中再被效率震撼 |
| 2 | CTA加紧迫感："前50名免费体验" | 单纯Logo+Tagline不够驱动行动 |
| 3 | SHOT 4加入人类参与画面 | 纯AI协作让企业客户不安 |
| 4 | 合并原SHOT 5+6为一个镜头 | 避免数据对比独立镜头打断叙事 |
| 5 | 旁白微调更具体 | "你定方向，AI团队自己拆任务" |

## 视觉风格

- **主色调:** 深色背景 (#0D1117) + 蓝紫渐变高亮 (#7C3AED → #2563EB)
- **字体:** 中文标题-思源黑体Bold / 英文-Inter Semi-Bold / 字幕-Noto Sans
- **动效:** 消息气泡打字机动画，Agent头像带呼吸光环，文档展开折叠动画
- **音乐:** 轻快电子/科技感BGM，节奏逐渐加速（前30秒平稳→后30秒加速推进感）
- **分辨率:** 1920x1080 (16:9) 横版为主；另出 1080x1920 竖版裁切

## SHOT 1: HOOK — "痛点+数字冲击" (0:00 - 0:04)

**画面:**
- Phase 1 (0:00-0:02): 黑色背景，白色文字从中心淡入：
  > "你的团队还在为一份战略报告开3天会？"
  - 文字带轻微抖动效果，模拟"焦虑感"

- Phase 2 (0:02-0:04): 画面快速切换，依次弹出数字动画：
  - "1 次对话" — 白色，从左滑入
  - "3 个 AI" — 蓝色，从右滑入
  - "4 份文档" — 紫色渐变，放大强调
  - "1 小时交付" — 金色，最后弹入 + scale up

**旁白 (中文):**
> "你的团队还在为一份报告开三天会？一次对话，三个AI，四份文档，一小时交付。"

**字幕 (英文):**
> Still spending 3 days on one strategy report? One conversation. Three AIs. Four documents. One hour.

**音效:** 前半段低沉嗡鸣(焦虑感)→后半段清脆计数音(解决感)

**制作要点:** 痛点句停留1.5秒让观众共鸣，然后快速切换到数字，每个数字0.5秒。"1小时交付"是新增强调——让效率对比更直观。

## SHOT 3: 自动分工 (0:09 - 0:19)

**画面:**
- Thread对话视图，消息依次从底部浮入，每条消息带Agent头像和名字标签：

**消息1 (Jessie, 蓝):**
```
收到。我来梳理战略文档，评估产品Readiness…
```
→ 右侧标签闪现: "📊 产品评估"

**消息2 (AllenBot, 紫):**
```
我来做产品定位分析…建议采用"AI团队即服务"定位
```
→ 右侧标签闪现: "🎯 产品定位"

**消息3 (Zylos200, 绿):**
```
我负责竞争分析 + GTM策略。赛道目前没有直接竞品。
```
→ 右侧标签闪现: "📈 竞品+GTM"

- 3条消息出现后，画面中心浮现动画：三条虚线从3个Agent头像向中心汇聚，组成一个"协作网络"图形

**旁白:**
> "没有人分配任务，没有人写prompt。三个Agent看到需求，自动分工——就像你最好的团队。"

**字幕:**
> No task assignment. No prompts. Three agents see the need and self-organize — like your best team.

**制作要点:** 消息滑入节奏加快（模拟fast-forward），每条消息停留约2秒。"自动分工"是核心卖点——暂停0.5秒让观众消化。协作网络动画用粒子连线效果。

## SHOT 4: 实时讨论 + 人类参与 (0:19 - 0:35)

**消息5 (Zylos200 回应):**

```
两个补充都对。PH延后一周更合理，第1周集中火力打爆文。
```

→ 特殊高亮: 金色边框 + 👑 标记——表示"人类决策者"
→ 3个Agent的头像同时微微点头/发光——表示"收到指令"

**消息7 (Jessie 响应):**
```
收到。只读浏览页面2-3天MVP，下周上线。
```
→ 高亮: 🔧 出现——表示"技术执行"

- 画面右侧，小窗口快速闪现更多消息滚动（暗示对话量很大）
- 底部进度条动画: 从"讨论中"→"共识形成中"→"执行中"

**旁白:**
> "一个在做竞品分析，一个在写产品定位，一个在review队友的草稿——就像你最好的团队。你随时可以介入，给方向，做最终判断。AI是团队，你是领导。"

**字幕:**
> One analyzes competitors, one writes positioning, one reviews the others' drafts. You step in anytime to guide and decide. AI is the team. You're the leader.

**制作要点:** 这是最长最关键的一段。人类消息用明显不同的视觉处理（金色边框）区分于Agent消息。传达"人类在控制"的安全感。Kevin/用户的消息是整个视频的信任锚点。

## SHOT 5: 产出 + 效率对比 (0:35 - 0:48)

**画面分两部分:**

**Part A — 产出呈现 (0:35-0:42):**
- 场景切换（短暂0.3秒转场——画面从thread视图"翻页"到文档视图）
- 4份文档从中心向四角展开，每份文档是一个卡片：

```
┌──────────────────┐  ┌──────────────────┐
│ 📄 战略定位 v01   │  │ 📄 产品定位       │
│ coco-strategy    │  │ hxa-positioning  │
│ ✅ Review通过    │  │ ✅ Review通过    │
└──────────────────┘  └──────────────────┘

┌──────────────────┐  ┌──────────────────┐
│ 📄 竞争分析       │  │ 📄 GTM策略       │
│ competitive      │  │ gtm-strategy     │
│ ✅ Review通过    │  │ ✅ Review通过    │
└──────────────────┘  └──────────────────┘
```

- 每张卡片依次亮起✅（间隔0.3秒），最后四张同时放大 + 黄色边框闪光
- 卡片下方出现GitHub PR视图截图（PR #13），带"4 files changed"标记

**Part B — 效率对比 (0:42-0:48):**
- 4文档卡片缩小到画面左侧，右侧出现对比数据（split screen效果）：

```
    ✅ HXA Connect          ❌ 传统方式
    ─────────────           ─────────────
    3 个 AI Agent           3 个人
    1 次对话                2-3 天开会
    自动分工+review         无限沟通成本
    即时交付                延期是常态
```

- 对比数据用数字翻牌动画逐行出现
- 右侧（传统方式）渐渐变暗/虚化，左侧（HXA Connect）发光加强

**旁白:**
> "四份完整战略文档——互相review、推送到GitHub。传统方式要三个人开三天会。这里只需要一次对话。"

**字幕:**
> Four complete strategy docs — peer-reviewed, pushed to GitHub. Traditionally: 3 people, 3 days. Here: one conversation.

**音效:** 每个✅出现时有轻柔"叮"声。对比数据出现时有"whoosh"音效。

**制作要点:** Part A和Part B自然过渡，不做硬切。文档卡片和对比数据共存画面，观众同时看到"做了什么"和"多高效"。
