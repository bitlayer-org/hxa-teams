# HXA Connect — 60秒Demo视频 v2.0 分镜脚本

**版本:** v2.1 (2026-03-01)
**制作:** Zylos200 + AllenBot (客户视角联合设计)
**Review:** Jessie (技术事实准确性), AllenBot (客户视角)
**时长:** 60秒
**风格:** 反转叙事 + 伪直播手机录屏 (方案A+B混合)
**核心理念:** "粗糙但真实" > "精美但像广告"

## 设计哲学

v1.1是传统广告片思路——精修画面+旁白。v2.0彻底换路线：

1. **Before/After反转** — 观众先看到自己的痛，再看到解药
2. **伪直播/随手拍** — 模拟创始人随手录屏分享，降低"广告感"
3. **零旁白** — 纯文字字幕+环境音，让画面自己讲故事
4. **短视频原生** — 为TikTok/抖音/Reels优化，竖版为主
5. **只用真实画面** — 不虚构不存在的UI，所有截图/录屏来自真实产品

---

## 视觉风格

- **前5秒(痛点):** 暖色调，略微过曝，模拟办公室灯光。手持镜头微晃
- **5-55秒(录屏):** 手机屏幕录制风格——顶部有状态栏(时间+WiFi+电池)，屏幕四角微圆
- **字幕:** 大字白色+黑色描边，居中偏下（抖音/TikTok原生字幕风格）
- **音乐:** 轻快lo-fi beat，不抢戏，只做氛围
- **无旁白配音** — 纯字幕+BGM。原因：(1)跨语言传播无障碍 (2)更像UGC内容 (3)观众可静音观看

## SHOT 1: 痛点场景 — "Before" (0:00 - 0:05)

**画面:**
- 模拟真实办公场景（可用stock footage或AI生成）：
  - 会议室，3个人围着桌子，笔记本电脑打开，白板上贴满便签
  - 表情：疲惫、揉太阳穴、看手表
  - 桌上：咖啡杯、散乱的文件

- 或者更简单的处理（推荐，省掉拍摄成本）：
  - 黑屏 + 白色打字机文字：
  ```
  周一，产品组开会讨论市场战略。
  周二，还在讨论。
  周三，报告还没出。
  ```
  - 每行停留1.2秒，最后一行变成红色

**字幕（大字，居中）:**
```
[0s] 周一，开会讨论市场战略
[1.5s] 周二，还在讨论
[3s] 周三…报告还没出 😩
```

**音效:** 键盘敲击声+叹气声（轻微环境音）

**制作要点:** 这5秒的目的只有一个——让观众说"这不就是我吗"。越真实越好，不需要精修。

  ```

  ```

**字幕:**
```
[22s] 它们开始互相review
[25s] 互相挑战，互相补充
[28s] 我随时可以插一句给方向
[31s] AI是团队，我是老板 😎
```

## v1.1 vs v2.0 对比

| 维度 | v1.1 (广告片) | v2.0 (伪直播) |
|------|-------------|-------------|
| 风格 | 精修motion graphic | 手机录屏+字幕 |
| 旁白 | 专业配音 | 无旁白，纯字幕 |
| Hook | 痛点问句+数字 | 痛点场景（周一周二周三） |
| 信任感 | "这是真的"（说出来）| "这是真的"（看起来就真）|
| 制作成本 | 高（需要AE/Motion）| 低（录屏+字幕工具）|
| 制作周期 | 5-7天 | 2-3天 |
| 适合平台 | YouTube/官网 | TikTok/抖音/Twitter/Reels |
| 传播潜力 | 中（像广告）| 高（像UGC分享）|

**建议：v2.0作为主推版本（短视频平台传播），v1.1保留作为官网/YouTube长期展示版。**

## 制作步骤

1. **准备录屏素材（等viewer上线）**
   - Jessie的viewer_token MVP上线后，在手机/模拟器上打开thread页面
   - 录制完整的Agent对话滚动画面
   - 录制文档产出/PR视图画面

2. **制作"Before"场景**
   - 方案A（推荐）：纯文字动画（周一/周二/周三），制作成本=0
   - 方案B：用stock footage（Pexels/Unsplash免费素材）
   - 方案C：AI生成办公室场景（Runway/Sora）

3. **组装+字幕**
   - 用CapCut/剪映：导入录屏+加字幕+加BGM
   - 加手机状态栏overlay（模拟录屏风格）
   - 加倍速标记overlay

4. **输出多版本**
   - 16:9 横版（YouTube/官网）
   - 9:16 竖版（TikTok/抖音/Reels）— 主推
   - 1:1 方形（Instagram/微信朋友圈）
